# Anchored audit 1.3.2: frozen outcome

The completed run returned 23 inconclusive outcomes and two no-error-reported outcomes across 25 cases. It confirmed no material error. All 57 model calls completed with schema-valid output. These mechanical gains did not demonstrate reliable factual discrimination.

The critic repeatedly misclassified ordinary answer-versus-source comparisons as cross-source conflicts. The two-distinct-passage guard stopped 44 proposed confirmations. The guard preserves uncertainty rather than inventing evidence, but the overall design is too inconclusive for an answer gate. Nineteen model confirmations rejected objections as not demonstrated and two remained uncertain.

Freeze this version and retain its raw bundle. The next experiment reuses the baseline selection/generation component without a model gate, records candidates and their citation mappings, and assesses factual correctness separately from semantic citation support. It does not modify the deployed answer route or claim the factuality problem is solved.
