01 / THE PROJECT

Can the answer survive
a change in evidence order?

EvidenceShift examines the reliability of document-grounded answers across Qwen 3 4B, Qwen 3 8B and Gemma 3 4B. I compare saved outputs with their source passages to check factual support, citation use and abstention.

02 / WHAT WE ARE TESTING

A cited answer still needs checking.

What usually happens

A document QA system retrieves relevant passages and supplies them to a model, which returns an answer with citations. A citation shows where to look; its presence alone does not establish that the answer follows from the passage.

The experiment

If the question and evidence stay the same, does changing passage order change the answer? I also check whether models preserve conditions, distinguish people and events, and abstain when the supplied text does not contain an answer.

03 / HOW WE TEST AND EVALUATE

Same inputs.
Separate checks.

The local project uses MiniLM/Chroma semantic document retrieval. These recorded comparisons start with fixed saved passages, so they isolate response behavior without rerunning retrieval.

Full methodology ↗
01

Supply the same evidence in two orders

Keep the question, model, passage text, source IDs and request options fixed within each pair. Run the original passage order, then its exact reverse.

02

Test three complementary protocols

Compare direct answers across all three models; compare whole-passage and text-unit ID selection across all three; then examine eight additional fictional cases using Qwen 3 8B. The last protocol contains only that model.

03

Review meaning as well as format

Software checks completion, citation IDs and prescribed abstention. I manually review factual support, citation relevance, qualifications and completeness against the saved passages. Failures and incomplete outputs remain in the record.

How to read the counts

The three protocols use different cases and output formats, so their results are reported separately. No-context records are code controls that make no model call; they are excluded from model-call totals. Changing a website selection displays saved data and does not run inference.

05 / CONCLUSIONS

A citation is a pointer, not proof.

Across these saved tests, valid citations and completed responses still accompanied wrong facts, contradictions and false abstentions. Reversing the same evidence sometimes changed a supported answer into an incorrect one.

Qwen 3 8B produced more usable direct answers than Qwen 3 4B under this setup, but still made factual errors. Gemma 3 4B completed every direct-answer trial, yet its outputs included contradictions and unsupported claims.

EvidenceShift exposes a gap between citing a source and reasoning faithfully from it. Evaluate what the evidence actually supports, including relevance, completeness and appropriate abstention.

These findings describe the tested cases and configurations; they do not establish a universal model ranking.
